# Desktop Dungeons（桌面地下城）
本作编程方面非常特别，大量使用继承和重写而不是组合，主要的游戏逻辑几乎全是虚方法，而且完全没有考虑线程安全

### steam-[DesktopDungeons]-x86-dffc5c9f6ea4ba8772a8ee17fa2e8b0f2f47f4f8

- `#3` 对**死亡防护**无效
- 激活 `#6` 会进入一个从下往上且从左往右的开图流程，由于游戏编码没考虑线程安全，这个过程可能会导致游戏崩溃，如果崩溃非常频繁可双击打开脚本，找到 `sleep(20)` 这一行，将 20 改为 50 甚至 100 等更大的数值，如果问题依旧建议使用 `#5` 代替
