# Shadow Warrior 3（影子武士 3）

### steam-[SW3]-amd64-4185a4e642b1049748f82f392adc7a27f647d843
> 由于此游戏内部实现方式原因，修改 UFunction 不太现实，所以都提供了具体的数值指针以供锁定
- 从武器切换到武士刀时武器会后台重装填，因此如果是冲锋枪锁定**当前子弹**数量低于 64 时会导致备弹越来越少，这是预期现象但不影响实际效果
- **当前武器伤害**似乎仅对手枪和冲锋枪生效
- 比起锁定**生命值**更建议锁定**护盾值**
- 两个升级点数相关，实际能使用的点数需要同步修改，比如**武器升级总点数**为 8，**武器升级可用点数**为 3，即当前消耗了 5 点，如果想从 3 点改成 10 点，需要将总点数改为 15，可用点数改为 10
